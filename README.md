\# Corvane Fleet — AI Visibility Tracker



A locally runnable AI visibility and accuracy tracker built for Corvane Fleet. It monitors ChatGPT, Perplexity, and Google AI Overviews across 15 buyer queries over a 6-week timeseries, detecting brand mentions, sentiment tone, ground-truth contradictions, and computing a normalized executive visibility score.



\---



\## 🚀 How to Run Locally



\### 1. Prerequisites

Ensure Python 3.10+ is installed on your machine.



\### 2. Setup \& Installation

```bash

\# Clone the repository

git clone https://github.com/krishnaprajapati2020-hue/corvane-ai-visibility-tracker/tree/main

cd corvane-ai-visibility-tracker



\# Install required dependencies
